Citing the Index

To cite the Dissensus Index as a whole:

Dissensus Index. dissensusindex.com. Accessed [month day, year].

Citing a specific case

To cite a specific case entry:

Dissensus Index, case [ACI-XXXX-XXX], methodology v[version], accessed [month day, year]. dissensusindex.com/case.html?id=[case-id].

Example:

Dissensus Index, case ACI-001, methodology v1.1, accessed October 9, 2026. dissensusindex.com/case.html?id=ACI-001.

Because case entries are updated as controversies develop, researchers should note the date they accessed the record.

An ACI number is a permanent identifier for a single case. It is never reassigned, and the sequence may be non-contiguous: a missing number simply means a candidate case did not clear editorial review. Once published, a case keeps its number for good, so a citation always resolves to the same record.

Citing the dataset

The full dataset is available for download at dissensusindex.com/data/cases.json and will be archived with a DOI via Zenodo at each quarterly release. To cite the dataset:

The Dissensus Index. Dissensus Index Dataset, v[version], [year]. dissensusindex.com/data/cases.json. DOI: forthcoming.

Citing the methodology

The methodology is versioned. To cite the methodology in use during a specific observation period:

Dissensus Index, Methodology v1.1. Effective October 9, 2026. dissensusindex.com/methodology.html.

Press and journalism

Journalists citing the Index in published work may use the short form: the Dissensus Index on first reference, the Index thereafter. Please include dissensusindex.com.

For interview requests or data inquiries, contact via dissensusindex.com.
